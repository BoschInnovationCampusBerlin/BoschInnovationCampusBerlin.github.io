# IT Infractructure
* LLM models​
* Runtime for multi-agent frameworks ​
* Document version control repository

# Key components
* A root agent for orchestration​
* Reviewer agent(s) for different aspects, e.g., Arc42 format guideline agent, or TOGAF best practices agent ​
* Tools for accomplishing the tasks, e.g., to read the architecture documents, update them, or to read the guidelines​

# Challenge
Creating the multi-agent set up considering different aspects of architecture documentation. We propose to create different agents for addressing different aspects, e.g., e.g. Arc42 format guideline agent, or TOGAF best practices agent, etc. The goal is to have an extendable mechanism for further supporting additional aspects​
